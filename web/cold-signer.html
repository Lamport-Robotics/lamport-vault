Cold signer

One file. No network. Your words stay where they are.

The cold signer is a single HTML page. It needs nothing from the internet and sends nothing to it. You run it on a machine with the network off, give it the request the vault page prepared, type the words, and carry the signature back.

The round trip

1 · Download
Get lamport-vault-signer.html once and keep it. It does not change between withdrawals.
2 · Prepare
On the vault page, choose the action and amount, then Prepare request. Copy it, or show it as a QR code.
3 · Go offline
Open the file on a machine with Wi-Fi and cables off. The page shows a red pill while it still sees a network; wait for it to turn.
4 · Sign
Paste or scan the request, check that the destination and amount are what you meant, type the 24 words, press Sign. The signer records the key number it used before it signs, so the same key can never be used twice from that machine.
5 · Carry back
Copy the signature, save it as a file, or show it as QR frames. Paste it into the vault page and press Verify and execute.

Rules worth keeping

  • A request is valid for about an hour; after that, prepare a new one.
  • If you restore the offline machine from a backup, rotate the vault key before signing again. Its memory of used keys may be older than the chain's.
  • The words are typed only here. Never into the vault page, never into a chat, never into a photo.
